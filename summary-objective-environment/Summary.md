# Project Summary

This project was created to demonstrate practical Linux administration skills by applying the commands and concepts I learned to a realistic organizational environment.

The goal was to build a stable Linux-based environment for a community consisting of different teams, each with specific responsibilities and access requirements. Instead of demonstrating Linux commands individually, I used them together to create users and groups, configure directory ownership, manage permissions, assign additional access through ACLs, and establish shared resources.

The environment was designed around different roles, including the Management, Developers, and Security teams. Each team was given access according to its responsibilities, while the Security team was given broader administrative control over the environment.

After configuring the environment, I tested it using the different users to verify that authorized users could access the resources they needed while unauthorized users were prevented from accessing restricted directories.

The project therefore serves as a practical demonstration of Linux user management, groups, file ownership, permissions, ACLs, directory management, and permission testing within a realistic scenario.
