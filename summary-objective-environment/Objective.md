# Project Objective

The main objective of this project is to demonstrate practical Linux administration skills by applying the commands and concepts learned throughout my Linux studies to a realistic, functional environment.

Rather than demonstrating commands individually, the project aims to use them together to design and maintain a Linux environment for a community with multiple teams and different access requirements.

The project objectives are to:

* Create and manage multiple Linux users and groups based on organizational roles.
* Design a directory structure that represents resources belonging to different teams.
* Configure file and directory ownership using Linux ownership mechanisms.
* Apply appropriate permissions to control read, write, and execute access.
* Use Access Control Lists (ACLs) when standard Linux permissions are insufficient for the required access model.
* Provide controlled shared resources for collaboration between users.
* Give the Security team broader administrative access while maintaining appropriate restrictions for other teams.
* Prevent users from accessing resources outside of their assigned responsibilities.
* Test the environment using different user accounts to verify that the configured permissions behave as intended.
* Demonstrate that the resulting environment is stable, organized, and suitable for a realistic multi-user Linux system.

Ultimately, the objective is to demonstrate not only knowledge of individual Linux commands, but the ability to combine them to solve practical administration and access-control requirements in a realistic environment.
