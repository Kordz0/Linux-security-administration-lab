# Linux Users, Groups & Permissions Lab

A simple Linux lab that I personally built to demonstrate my hands-on experience with Linux and strengthen skills that are useful in penetration testing.

The lab focuses on Linux users, groups, file ownership, permissions, and access control. After configuring the environment, I tested the system from different user accounts to verify that the permissions worked as intended.

This project is meant to demonstrate practical Linux knowledge rather than just familiarity with commands, with a focus on understanding and testing how Linux access controls behave in real scenarios.
